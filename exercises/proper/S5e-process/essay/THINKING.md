# S5e 思考题（学生作答）

按你的理解作答；答案非空且命中关键字即可（如 `fork`/`复制`、`写时复制`/`CoW`、`缺页`、
`exec`/`替换`、`僵尸`/`zombie`/`wait`、`地址空间`/`隔离`）。

## Q1. `fork` 的语义是什么？为什么用写时复制（CoW）而不是整页复制？

（在此作答：父得子 PID、子得 0、父子各自地址空间；CoW 先共享只读、谁写谁拷，省内存省拷贝，
fork+exec 几乎零拷贝。）

## Q2. CoW 为什么必须配合缺页机制？分裂时内核具体做了什么？

（在此作答：只读页被写 → store 缺页是 CoW 的触发器；分裂 = 找帧 / 新帧拷贝 / 旧帧引用 -1 /
改页表恢复可写清 COW / sfence 后重执行；缺页不前移 sepc。）

## Q3. `exec` 与 `fork` 有何区别？`wait` 为什么要回收僵尸进程？

（在此作答：fork 复制造新进程，exec 替换当前进程地址空间、PID 不变；exit 后留退出码成僵尸，
父 wait 回收并取退出码，否则资源泄漏。）

## Q4. 对照 S8（单进程、无分页）：本实验的隔离强在哪？还有哪些没做？

（在此作答：S8 ch2 同地址空间、仅特权级隔离；本实验每进程独立 SV39 页表、切 satp、CoW 真隔离；
未做：栈 CoW / 页表回收 / ELF 加载 / 抢占 / vfork 等。）
